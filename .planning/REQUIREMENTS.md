# Requirements

## v1 — macOS Playable Build

### REQ-01: Boot & Title
Game boots from cold start to title screen on macOS Apple Silicon.

### REQ-02: Fight Mode
At least one fight mode playable: character select → fight → result.

### REQ-03: Input
Keyboard and gamepad input mapped to PS2 pad.

### REQ-04: Audio
Game audio plays (BGM, SFX, voice) via native audio backend.

### REQ-05: Performance
Sustained 60 FPS during gameplay.

### REQ-06: Video
FMV/IPU movie playback functional.

## v2 — Full Game + Cross-Platform

### REQ-07: All Modes
Story, VS, Practice, Gallery modes playable.

### REQ-08: All Characters
All 36+ characters selectable and playable.

### REQ-09: Save System
Memory card emulation — save/load game state.

### REQ-10: Cross-Platform
Builds for Windows, Linux, Android, iOS.

### REQ-11: Widescreen
16:9 aspect ratio support with resolution scaling.
